Project Overview & Motivation

Students and developers diving into Artificial Intelligence often face a fragmented experience: theoretical textbooks on one side and isolated code notebooks on the other. NeuroLearnX was engineered by Ayush Deval to solve this by providing a unified, AI-powered platform delivering personalized learning paths, an interactive AI tutor, hands-on ML experimentation labs, and automated performance analytics.

"NeuroLearnX bridges the gap between machine learning theory and practical model building with personalized curriculum adaptation and instant AI tutoring."

Core Engineering Features Delivered

As documented in Ayush Deval's resume, the platform successfully fulfilled three critical milestones:

  • Personalized Learning Paths & Interactive ML Labs: Dynamic recommendation system that tailors progression based on user knowledge gaps, accompanied by in-browser ML lab execution.
  • Hugging Face & LangChain Integration: Implemented AI-based recommendation and contextual question-answering engines utilizing open-source transformers and retrieval-augmented pipelines.
  • High-Performance Full-Stack Architecture: Engineered backend REST APIs in FastAPI with dual-database persistence (MongoDB for flexible telemetry & PostgreSQL for relational user progress), paired with a responsive React.js dashboard.

System Architecture & Data Pipeline

The platform architecture is divided into three key decoupled layers:

1

Interactive Frontend

React.js dashboard rendering real-time performance analytics, code editor interfaces for ML labs, and responsive tutoring chats.

2

FastAPI API Engine

Asynchronous REST endpoints managing authentication, lab execution state, PyTorch inference triggers, and MongoDB/PostgreSQL CRUD operations.

3

AI & LangChain Core

Hugging Face models embedded via LangChain chains to provide domain-grounded Q&A on machine learning concepts and code debugging assistance.

Technical Skills Applied

This project synthesized multiple core competencies from Ayush Deval's technical toolkit:

  • Python & PyTorch: Data modeling, custom evaluation scripts, and model loading.
  • FastAPI & REST APIs: High throughput, async request processing, and schema validation with Pydantic.
  • LangChain & Hugging Face: Prompt templates, vector indexing, and question-answering pipelines.
  • Databases: MongoDB for session histories, lab submissions, and conversational memory; PostgreSQL for relational user management and analytics.
  • Git & Development Tooling: Systematic Git feature branching and VS Code development environment.

Next Steps: Speech & Kubernetes Expansion

Following the completion of NeuroLearnX in December 2025, Ayush extended these AI architectures into the Multilingual Speech Translation Assistant (March–May 2026), incorporating OpenAI's Whisper model, text-to-speech transformers, Docker containers, and Kubernetes cluster orchestration.
